# Unlock-Music 启动流程

## 1. 进入项目目录

在 PowerShell 中执行：

```powershell
cd D:\SignIn\unlock-music
```

## 2. 确认 Node 环境

项目 `.nvmrc` 指定的是：

```text
v16.18.1
```

推荐使用 Node 16。如果当前使用 Node 17 及以上，Vue CLI 4 / webpack 4 可能遇到 OpenSSL 兼容问题，启动前需要在当前 PowerShell 会话中设置：

```powershell
$env:NODE_OPTIONS="--openssl-legacy-provider"
```

## 3. 安装依赖

当前项目已经临时移除了私有 registry 和 `@unlock-music/joox-crypto` 依赖，可以直接安装：

```powershell
npm install
```

说明：

- `.npmrc` 当前保持为空，不再指向 `https://git.unlock-music.dev/api/packages/um/npm/`
- JOOX 解密功能已临时禁用，其他格式解密功能可继续使用
- 如果重新拉取原始项目，可能会因为 `@unlock-music/joox-crypto` 返回 `403 Forbidden` 导致安装失败

## 4. 启动开发服务

```powershell
npm run serve -- --port 8080
```

启动成功后，终端会看到类似输出：

```text
Compiled successfully
App running at:
- Local: http://localhost:8080
```

浏览器访问：

```text
http://localhost:8080
```

## 5. 验证服务是否可访问

可以在 PowerShell 中执行：

```powershell
Invoke-WebRequest -UseBasicParsing http://localhost:8080 -TimeoutSec 10 | Select-Object StatusCode
```

如果返回 `200`，说明服务已经启动成功。

## 6. 停止服务

如果服务是在当前终端前台运行，按：

```text
Ctrl + C
```

如果服务是后台运行，先查找占用 `8080` 端口的进程：

```powershell
netstat -ano | Select-String ':8080'
```

然后停止对应 PID：

```powershell
Stop-Process -Id <PID>
```

## 常见问题

### `@unlock-music/joox-crypto` 安装 403

原因是原项目依赖了上游私有/受限 registry：

```text
https://git.unlock-music.dev/api/packages/um/npm/
```

当前工作区的处理方式是：

- 清空 `.npmrc`
- 从 `package.json` 和 `package-lock.json` 移除 `@unlock-music/joox-crypto`
- 将 `src/decrypt/joox.ts` 改为临时不可用提示

如果后续需要恢复 JOOX 解密，需要拿到上游 registry 权限或可用的 `joox-crypto` 包来源。

### `'vue-cli-service' is not recognized`

说明依赖没有安装成功，重新执行：

```powershell
npm install
```

### OpenSSL / webpack 报错

如果使用 Node 17 及以上，先设置：

```powershell
$env:NODE_OPTIONS="--openssl-legacy-provider"
```

再重新启动：

```powershell
npm run serve -- --port 8080
```
